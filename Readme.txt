# Bimtek PGRI POWER 2026
Aplikasi Web berbasis Google Apps Script (GAS) dan Google Sheets untuk registrasi peserta, pengumpulan tugas, dan portal unduh sertifikat mandiri pada kegiatan Bimtek PGRI POWER 16 September 2026.

## Fitur Utama
* **Form Registrasi Peserta:** Validasi email otomatis agar tidak ada data ganda.
* **Pengumpulan Tugas:** Peserta dapat mengirim atau memperbarui tautan tugas Google Drive.
* **Portal Sertifikat:** Integrasi pengecekan status tugas dan tautan unduh sertifikat (didukung oleh Autocrat).
* **Responsive Design:** Dibangun menggunakan Bootstrap 5, nyaman diakses via HP maupun Laptop.
